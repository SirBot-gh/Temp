<#
.SYNOPSIS
  Sanitize PAN-OS device state bundles: redact secrets in every XML file and
  write .txt copies with paths preserved.

.DESCRIPTION
  Accepts a device state archive (.tar / .tgz / .tar.gz) or an extracted folder,
  redacts known secret-bearing XML elements to the literal string REDACTED, runs a
  regex safety-net pass, verifies output, and writes MANIFEST.txt plus MANIFEST.json.
  Output is well-formed XML text with a .txt extension for tools that reject .xml.

  Per-bundle output under OutputRoot\<bundle-name>\:
    *.txt           sanitized XML text (relative paths preserved; .xml -> .txt)
    MANIFEST.txt    human-readable summary
    MANIFEST.json   machine-readable summary

  Do not share the raw bundle or unredacted extraction -- only the sanitized .txt
  files and manifests.

  Exit codes:
    0  success (all XML files sanitized)
    1  usage/input error, or -MaskIdentity (not implemented)
    2  post-write verification found leftover secrets (output folder deleted)
    3  one or more XML files failed to parse (fail-closed; no unsanitized write)

.PARAMETER InputPath
  Path to one archive, one extracted folder, or a folder containing several archives.

.PARAMETER OutputRoot
  Parent folder for per-bundle output subfolders.

.PARAMETER MaskIdentity
  Reserved. Tier 2 identity masking is not implemented in this release.
  If specified, the script prints a message and exits 1.

.PARAMETER Force
  Overwrite an existing per-bundle output subfolder. Without this switch the
  script refuses and exits 1 if the target subfolder already exists.

.PARAMETER WhatIf
  List files that would be written; write nothing. Requires SupportsShouldProcess.

.EXAMPLE
  .\Sanitize-DeviceState.ps1 -InputPath .\device_state_cfg.tgz -OutputRoot .\out

  Sanitize one archive into .\out\device_state_cfg\.

.EXAMPLE
  .\Sanitize-DeviceState.ps1 -InputPath .\extracted-bundle -OutputRoot .\out -Force

  Sanitize an already-extracted folder, overwriting a previous run.

.EXAMPLE
  Get-Help .\Sanitize-DeviceState.ps1 -Full

  Show this comment-based help, including parameters and exit codes.

.INPUTS
  None. You cannot pipe objects to this script.

.OUTPUTS
  None. Writes files under OutputRoot and returns an exit code.

.NOTES
  Windows PowerShell 5.1 and PowerShell 7+ on Windows 10/11.
  Keep this file ASCII (or UTF-8 with BOM). Windows PowerShell 5.1 reads
  BOM-less UTF-8 as the system ANSI code page; em-dashes then break parsing.
  $RedactElements is shared with Split-PanBundle.ps1 -- keep both lists identical.
  Requires tar.exe (ships with Windows 10 1803+ / Windows 11).
#>
